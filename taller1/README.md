## Objetivo del Taller
Construir una pantalla básica en Flutter haciendo uso de `StatefulWidget` para evidenciar el manejo de estado con `setState()`, integrando buenas prácticas de control de versiones con Git (ramas `main`, `dev` y `feature/taller1`).

## Pasos para Ejecutar
1. Clonar el repositorio.
2. Navegar a la carpeta del proyecto:
   ```bash
   cd taller1
   ```
3. Obtener las dependencias:
   ```bash
   flutter pub get
   ```
4. Ejecutar la aplicación (asegúrate de tener un emulador abierto o dispositivo conectado, por ejemplo, linux):
   ```bash
   flutter run -d linux
   ```
